APA ITU DOM?

DOM adalah antarmuka pemrograman (API) yang disediakan oleh browser untuk merepresentasikan dokumen HTML atau XML ke dalam struktur pohon (tree structure).

DOM adalah jembatan antara HTML dan JavaScript
