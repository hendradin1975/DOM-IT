# DOM-IT — Kelompok HTML

## Deskripsi

DOM-IT adalah website pembelajaran yang memperkenalkan **Document Object Model (DOM)**, yaitu antarmuka yang memungkinkan JavaScript mengakses dan memanipulasi elemen pada dokumen HTML.

Website ini dirancang agar pengguna dapat memahami dasar-dasar DOM melalui tampilan visual yang menarik, penjelasan singkat, dan materi yang disusun secara terstruktur.

### Tema Tampilan

Website ini menggunakan tema **gelap (dark theme)** dengan nuansa ungu gelap, krem, dan cokelat keemasan. Desainnya menggabungkan gaya modern dengan latar belakang bergambar, lapisan transparan, serta kartu informasi yang memiliki efek kaca (*glassmorphism*).

Tampilan dibuat untuk memberikan kesan elegan dan nyaman dilihat, sekaligus membantu pengguna mengenali materi yang disajikan.

### Palet Warna

| **Peran** | **Kode Warna** | **Penggunaan** |
|---|---|---|
| Latar utama | `#290024` | Latar ungu gelap |
| Teks utama | `#F2F5E2` | Judul dan teks informasi |
| Aksen krem | `#E3DEA4` | Warna pendukung |
| Aksen utama | `#D4954D` | Tombol NEXT dan elemen penekanan |
| Aksen cokelat | `#775533` | Variasi warna kartu |
| Lapisan transparan | `rgba(41, 0, 36, 0.7)` | Lapisan di atas gambar latar |

- **Tombol utama:** menggunakan warna `#D4954D` untuk membedakan tombol navigasi dari konten lainnya.
- **Kartu informasi:** menggunakan warna ungu transparan dengan garis tepi tipis dan efek blur.
- **Latar belakang:** menggunakan gambar dengan ukuran menyesuaikan area halaman.

### Tipografi

Website menggunakan beberapa jenis font untuk membedakan judul dan isi konten.

- **Outfit ExtraBold** untuk judul utama dan judul bagian.
- **Druk** untuk judul kartu fitur.
- **Montserrat** untuk teks penjelasan pada kartu.
- **Font tambahan:** One Piece, Strong, Luxena, dan MountSagilite tersedia untuk kebutuhan desain lainnya.

### Ciri Visual

- Latar belakang berupa gambar yang menyesuaikan ukuran layar.
- Lapisan ungu transparan untuk menyatukan warna latar dengan konten.
- Efek kaca (*glassmorphism*) pada kartu fitur.
- Sudut membulat pada kotak informasi dan tombol navigasi.
- Ilustrasi struktur pohon DOM sebagai pendukung penjelasan.
- Animasi teks berjalan dengan efek transparansi pada bagian awal dan akhir.
- Tata letak menggunakan Flexbox untuk menyusun konten.
- Ukuran elemen menyesuaikan ukuran layar melalui variabel CSS.
- Navigasi ant halaman menggunakan tombol NEXT.

### Isi Website

- **Beranda:** menampilkan judul DOM-IT dan pengenalan singkat tentang DOM.
- **Penjelasan DOM:** menjelaskan DOM sebagai struktur pohon dokumen HTML atau XML dan penghubung antara HTML dengan JavaScript.
- **Fitur DOM:** memperkenalkan empat operasi dasar, yaitu mengakses elemen, mengedit isi, menambahkan elemen, dan menghapus elemen.
- **Navigasi:** menyediakan tombol NEXT untuk berpindah ke halaman berikutnya.
- **Halaman anggota:** menyediakan halaman lanjutan yang dapat diakses melalui navigasi website.

### Teknologi yang Digunakan

| **Teknologi** | **Fungsi** |
|---|---|
| HTML5 | Membuat struktur halaman website |
| CSS3 | Mengatur tampilan, warna, tata letak, dan animasi |
| Flexbox | Menyusun elemen secara horizontal dan vertikal |
| CSS Variables | Menyimpan warna tema dan nilai ukuran yang digunakan berulang |
| Custom Fonts | Menggunakan font tambahan untuk memperkuat identitas visual |
